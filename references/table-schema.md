## 字段顺序

1. `记录标题`
2. `场所编号`
3. `一级领域`
4. `二级领域`
5. `简称`
6. `英文全称`
7. `中文参考名`
8. `类型`
9. `组织方/出版社`
10. `出版载体`
11. `投稿节奏`
12. `主要主题`
13. `适合稿件`
14. `审稿与提交特点`
15. `开放获取/费用模式`
16. `当前届次`
17. `会议开始日期`
18. `会议结束日期`
19. `地点`
20. `当前投稿节点`
21. `官方主页`
22. `投稿/CFP入口`
23. `场所信息引用建议`
24. `CCF/JCR/中科院分区`
25. `信息状态`
26. `核验日期`
27. `备注`

机器可用表头：

```tsv
记录标题	场所编号	一级领域	二级领域	简称	英文全称	中文参考名	类型	组织方/出版社	出版载体	投稿节奏	主要主题	适合稿件	审稿与提交特点	开放获取/费用模式	当前届次	会议开始日期	会议结束日期	地点	当前投稿节点	官方主页	投稿/CFP入口	场所信息引用建议	CCF/JCR/中科院分区	信息状态	核验日期	备注
```

## 字段填写规则

| 字段 | 规则 |
|---|---|
| 记录标题 | `简称｜英文全称`；作为飞书索引列。 |
| 场所编号 | 只在能检查现有编号时填写；否则留空。 |
| 一级领域 | 使用规定单选值。 |
| 二级领域 | 用稳定的学科方向短语，如“机器学习综合”“教育数据挖掘”。 |
| 简称 | 使用官方或广泛采用的简称，保留 `@`、连字符等正式符号。 |
| 英文全称 | 使用官方当前名称，不自行扩写简称。 |
| 中文参考名 | 简洁参考译名；没有稳定译名时可按英文含义翻译并在备注说明。 |
| 类型 | 使用规定单选值。 |
| 组织方/出版社 | 会议填主办学会/基金会；期刊填出版机构或学会。 |
| 出版载体 | 填 proceedings、出版社平台或期刊载体。 |
| 投稿节奏 | 使用规定单选值。 |
| 主要主题 | 用中文列出核心范围，不复制整篇 CFP。 |
| 适合稿件 | 说明适合的方法、理论、系统、数据、实证或教育研究类型。 |
| 审稿与提交特点 | 仅写官方确认的双盲、OpenReview、多周期、多轨道、页数等关键规则。 |
| 开放获取/费用模式 | 仅写官方确认内容；费用不确定时不写金额。 |
| 当前届次 | 会议填最新已公布届次；期刊留空。 |
| 会议开始日期 | 会议填 ISO 日期；期刊留空。 |
| 会议结束日期 | 会议填 ISO 日期；期刊留空。 |
| 地点 | 会议填官方地点或“线上”；期刊按事实填“在线国际期刊”“国际期刊”或留空。 |
| 当前投稿节点 | 以核验日为准，使用规定单选值。 |
| 官方主页 | 优先使用系列或当前届次的官方主页。 |
| 投稿/CFP入口 | 使用当前 CFP、作者指南或 submission guide 的官方链接。 |
| 场所信息引用建议 | `English Full Name (ACRONYM), official website, accessed YYYY-MM-DD: URL`。 |
| CCF/JCR/中科院分区 | 默认写“请按投稿当年及本单位采用的最新版目录核验”。 |
| 信息状态 | 使用规定单选值。 |
| 核验日期 | 实际检索日期，ISO 格式。 |
| 备注 | 一句话说明投稿匹配边界、未核实项或来源冲突。 |

## 单选字段

### 一级领域

只能使用：

- `统计/机器学习与AI`：机器学习、统计学习、学习理论、数据挖掘、不确定性等方法型场所。
- `计算机AI`：综合 AI、NLP、视觉、知识表示、HCI、机器人等计算机场所。
- `AI+教育`：AIED、教育数据挖掘、学习分析、教育技术、智能教学等以教育或学习为中心的场所。

### 类型

只能使用：

- `会议`
- `期刊`
- `专题会议/研讨会`

### 投稿节奏

只能使用：

- `年度`
- `年度/多周期`
- `年度/ARR周期`
- `滚动`

### 当前投稿节点

只能使用：

- `滚动投稿`
- `投稿开放/截止日临近`
- `论文投稿开放/临近截止`
- `即将举行/投稿已截止`
- `即将举行/主会投稿已截止`
- `本届已结束/下一届待公告`

选择规则：期刊通常使用 `滚动投稿`；会议投稿仍开放时使用两个“开放/临近截止”选项中与官方措辞和原表惯例最接近的一项；会议尚未召开但投稿已关闭时使用“即将举行”类；会议已结束且下一届未公告时使用 `本届已结束/下一届待公告`。无法确定时不要猜，在备注说明并将 `信息状态` 降为需复核。

### 信息状态

只能使用：

- `官方已核验`
- `官方主页已列/细节提交前复核`

只有主页、CFP/作者指南和关键日期或规则均得到官方页面支持时使用 `官方已核验`。否则使用第二项，并在备注指出缺口。

## 场所编号

前缀规则：

| 类型与领域 | 前缀 |
|---|---|
| AI/计算机会议或专题会议 | `C-AI-` |
| AI+教育会议或专题会议 | `C-EDU-` |
| AI/计算机期刊 | `J-AI-` |
| AI+教育期刊 | `J-EDU-` |

编号使用三位数，如 `C-EDU-008`。必须先读取目标表并检查同前缀的最大已用编号和是否已有同一场所；无法检查时留空，不能根据记忆分配。

## 默认聊天输出

先给简短核验摘要和官方来源链接，再给完整 TSV。TSV 必须：

- 包含一次完整表头；
- 使用真实制表符分隔；
- 每条记录独占一行；
- 每行严格 27 列；
- 单元格内部不得包含制表符或换行；
- 未知、不适用字段保留空列；
- 不用 Markdown 竖线表代替。

输出前可按分隔符切分每行，验证字段数为 27。

## 文件输出

- XLSX：三张表依次为 `场所总表`、`字段与使用说明`、`飞书单选选项`。主表使用本文件的 27 列；说明表和选项表复用本文件规则。
- CSV：UTF-8，完整 27 列；包含逗号、引号或换行的值必须正确转义，但应先清除单元格内换行。
- TSV：UTF-8，完整 27 列，优先用于直接粘贴。
- Markdown：保留全部字段和官方来源，不以版面太宽为由删列。
- JSON：顶层数组；每个对象按 27 字段顺序写出；空值统一使用空字符串。
